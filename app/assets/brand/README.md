# Brand assets

Add the supplied files here (not included in this repository yet):

- `logo.svg` / `logo@3x.png`: primary logo
- `product.png`: product photo on a transparent background
- `product-setup-mode.png`: the toy showing its setup-mode light (for the setup screen)

Use them unaltered: no redrawing, recolouring, cropping into the product, or
aspect-ratio changes. The current leaf shapes in `lib/core/design/illustrations.dart`
are placeholders.
